# 坦克大战 · Tank Battle

一个使用原生 HTML + CSS + JavaScript 编写的经典《坦克大战》（Battle City）风格网页游戏，单文件即可运行。

## 玩法

- 控制绿色坦克，消灭不断出现的敌方坦克，保护底部的基地。
- 消灭全部敌人即可过关，敌人会越来越强、越来越多。
- 敌方坦克被击毁后可能掉落道具。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 `方向键` |
| 射击 | `空格` 或 `J` |
| 暂停 / 继续 | `P` |
| 开始 / 重新开始 | `Enter` |
| 音效开关 | 界面按钮 |

## 道具

- ⭐ **星星**：提升火力（最高 3 级，3 级可击穿钢板、双发）
- 🛡 **头盔**：获得 8 秒无敌护盾
- 💣 **手雷**：消灭场上所有敌人
- 🚙 **坦克**：增加一条生命

## 地图元素

- 🧱 **砖墙**：可被子弹摧毁
- ⛓ **钢板**：不可摧毁（3 级火力除外）
- 🌊 **河流**：坦克无法通过，子弹可穿过
- 🌲 **树林**：坦克可穿过，且能隐藏坦克
- 🚩 **基地**：被击中则游戏结束

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建步骤。

也可以通过 GitHub Pages 在线游玩（在仓库 Settings → Pages 中启用）。
